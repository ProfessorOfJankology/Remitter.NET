# Remitter.NET

Windows desktop client for the Remitter backend service.

Remitter.NET is the next-generation WPF client for Remitter. The backend service remains in the `ProfessorOfJankology/Remitter` repository and is the authority for shared queue state, HCN validation, payment allocation, receipting, locking, idempotency, reconciliation and audit history.

This repository owns the Windows operator experience, API client behaviour, local presentation state, import UX, remittance/email viewing and ESCompose integration.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/MIGRATION.md](docs/MIGRATION.md).
